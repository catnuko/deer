## 0. 品牌定位（设计总纲）

**Deer = 有 AI 伴读的电子书阅读器。**

三句话纪律，所有设计决策遇到分歧时回到这里裁决：

1. **先是一本阅读器**——导入、读、标注、回看是产品骨架，排版优先，界面为长时间阅读服务。
2. **AI 伴读是差异化**——assistant-ui 的对话组件语言是核心资产：选中即问、边读边聊、聊完沉淀成笔记。
3. **工具感、克制**——「Deer 是电子书阅读器，不是杂志」：不做推荐流、不做花哨视觉、不做社交。能不出现的元素一律不出现。

MVP 四纪律同样约束视觉：只关注功能与快速迭代、不在乎样式打磨（指不追求装饰性，不是可以做得难看）、克制范围蔓延。

## 1. 全局设计规范

### 1.1 色彩（基线，UI 可在 Penpot 里微调后回填定稿）

> **catnuko 已拍板（2026-10-28）：主色调不延续苔绿（#2E7D5B 作废），改用温暖色系。** 下表为 PM 给的暖色基线建议，UI 在此基础上定稿，要求整体气质温暖、安静、适合长时间阅读，不作杂志式花哨。

| 令牌 | 值（暖色基线建议） | 用途 |
|---|---|---|
| `--background` | #FFFFFF（暗色 #1C1917 系） | 页面底色 |
| `--background-muted` | #FAF7F2（暖纸灰，侧栏、次级区域底） | 侧栏、次级区域底 |
| `--border` | #E7E2D9（暖灰描边） | 描边、分隔线 |
| `--foreground` | #292524（暖黑） | 主文字 |
| `--foreground-muted` | #78716C | 次级文字、说明 |
| `--primary` | #C2703D（陶土橙，UI 可微调） | 主按钮、选中态、进度、链接 |
| `--primary-foreground` | #FFFFFF | 主按钮上的文字 |
| `--destructive` | #DC2626 | 删除、危险操作 |
| 高亮 5 色 | 黄 #FDE68A / 绿 #A7F3D0 / 蓝 #BFDBFE / 粉 #FBCFE8 / 紫 #DDD6FE | 划线高亮底色（内容标注色，与主色无关，保留） |

明暗两套都要出：暗色模式底暖黑 #1C1917 系、文字 #E7E5E4 系、primary 提亮一档（如 #E8956A 或同明度暖橙），由 UI 定稿并保证对比度 ≥ 4.5:1。全文其余出现的「苔绿」「#2E7D5B」「#E7F3EE」一律按新主色 token 替换。

### 1.2 字体与排版

- 界面字体：system-ui 栈（PingFang SC / Noto Sans SC 兜底）；**书正文字体单独出选择**：衬线（Noto Serif SC）为默认，无衬线可切换。
- 字阶 5 级：12（辅助）/ 14（正文 UI）/ 16（书正文默认）/ 20（小标题）/ 28（页面标题）。
- 书正文排版是本产品的脸面，阅读页必须给出可调参数的设计呈现（见 §3.3）。

### 1.3 布局与间距

- 间距基准 4px，常用 4/8/12/16/24/32。
- 圆角：按钮 8px、卡片 12px、面板/弹层 16px、头像圆形。
- 触控/点击目标 ≥ 36px（桌面 Web），主操作 40–48px。
- 断点：≥1280（三栏：导航 + 主区 + AI 面板）/ 1024–1279（AI 面板改抽屉）/ <1024（导航折叠为图标栏，AI 面板为覆盖层）。仅桌面 Web，不出移动端稿。

### 1.4 图标

- 统一线性图标风格（lucide 语言），1.5–2px 描边，16/20/24 三档。
- 文档末尾附录给出每个页面需要的图标清单。

## 2. 页面一：书架（首页）

### 2.1 布局

- 左侧固定导航栏（宽 220px，<1280 折叠为 64px 图标栏）：Logo「Deer」+ 导航项（书架 / 笔记 / 设置）+ 底部「导入书籍」按钮。
- 主区顶部：搜索框（placeholder「搜索书名或作者」，⌘K 提示角标）+ 排序切换（最近阅读 / 添加时间 / 书名）+ 视图切换（网格 / 列表）。
- 主区两段：**继续阅读**（横排 3–4 张「进行中」卡片，带进度条与上次读到的时间）+ **全部书籍**网格。

### 2.2 书籍卡片

- 网格卡：封面（缺封面用首字占位块，主色浅底 + 书名首字）、书名（一行截断）、作者（次级色）、进度条 + 百分比、未读标记。
- hover 态：卡片上浮 2px + 阴影加深 + 右上角出现「⋯」更多按钮。
- 点击卡片 → 进入阅读页；「⋯」→ 下拉菜单：**继续阅读 / 标记完成 / 从书架移除**（移除需二次确认，destructive 红字）。
- 列表视图：行式（小封面 48px + 书名 + 作者 + 进度 + 最近阅读时间），行 hover 浅灰底。

### 2.3 状态设计（每个都要出）

- **空态**：插画位 + 「书架还是空的」+ 主按钮「导入第一本书」+ 说明「支持 epub / txt」。
- **导入中**：书架顶部细进度条；卡片骨架屏（灰块 shimmer）。
- **导入失败**：toast 错误样式（红描边卡片：失败原因 + 「重试」按钮）。
- **加载**：骨架屏，不出 spinner 转圈为唯一状态。
- **搜索无结果**：「没有找到与“××”匹配的书籍」+ 清除搜索按钮。

## 3. 页面二：阅读页（产品核心）

### 3.1 布局

- 顶栏（悬浮，滚动时半透明毛玻璃，静止 2s 后自动隐藏，鼠标上移至顶部重现）：返回书架、书名居中、右侧图标组：**目录 / 搜索本书 / 排版设置 / AI 伴读开关 / 更多（书详情）**。
- 正文列居中，最大页宽可调（见 3.3），左右留白充足。
- 右侧 AI 面板（宽 400px，可折叠）：见 §4。
- 底部：当前章节名 + 阅读进度百分比（细条，不作视觉重心）。

### 3.2 目录抽屉（点顶栏「目录」）

- 左侧滑出抽屉 300px：书名 + 章节树，当前章节高亮（主色左竖条 3px），已读章节打勾。
- 行 hover 浅灰，点击跳转并关闭抽屉。显示每章进度可不做（克制）。

### 3.3 排版设置弹层（点顶栏「排版设置」）

Popover 弹层，四组控件，改动即时生效并出预览：

- **字号**： stepper（A− / A+）+ 档位显示（14–24px，步进 2）。
- **行距**：三档分段选择器（紧凑 1.5 / 适中 1.8 / 宽松 2.2）。
- **页宽**：三档分段选择器（窄 36em / 中 42em / 宽 48em）。
- **正文字体**：两档分段选择器（衬线 / 无衬线）。
- 底部「恢复默认」文字按钮。

### 3.4 划选正文 → 弹出工具条（重点细节）

划选后，在选区上方 8px 居中浮出工具条（深墨底 #111827、白字、圆角 8px、小三角指向选区）：

按钮从左到右：**问 AI**（主操作，主色填充）｜**高亮**（点开展开 5 色色板）｜**笔记**｜**复制**。

- 「高亮」点击后原位展开色板：5 个色点（黄绿蓝粉紫）+「清除」。选中颜色后选区变为该色高亮、工具条消失。
- 「问 AI」：AI 面板自动展开（若折叠）→ 自动在 composer 里预填引用块「[选中文本前 60 字…]」→ 光标落在输入框，用户补一句就发送。
- 「笔记」：AI 面板切到笔记侧、预填引用 + 笔记编辑态（见 §4.6）。
- 「复制」：复制纯文本，toast「已复制」1.5s 自动消失。
- 工具条出现动效：opacity 0→1 + 上移 4px，120ms ease-out；消失 80ms。
- 选区点击页面其他处即消失；选区跨页/滚动时工具条跟随选区锚点。

### 3.5 已有高亮的交互

- 点击高亮文本 → 弹出气泡菜单：**改色（5 色板）/ 问 AI（带该段上下文）/ 添加笔记 / 删除高亮**。
- 高亮若已挂笔记，气泡里多一行笔记摘要（一行截断）+「查看完整笔记」跳笔记页。
- 删除高亮：直接删 + toast「已删除」+「撤销」按钮（5s 内可撤销）。

### 3.6 翻页与滚动

- 滚动模式为默认（MVP 不做双页仿真翻页）。滚轮 / 触控板 / PageUp·PageDown / 空格（下屏）。
- 键盘 ←/→：滚动模式时为上/下一章节跳转（顶栏 hover 时有 tooltip 说明）。

### 3.7 阅读页状态

- 书加载中：正文列骨架屏（三行文字块 shimmer）。
- 打不开/文件损坏：居中空态「无法打开这本书」+ 原因 +「返回书架」。
- AI 面板折叠时右侧留 48px 细条，带「AI 伴读」竖排文字按钮可展开。

## 4. 页面三：AI 伴读面板（assistant-ui 主战场）

> 此面板整体采用 assistant-ui 的 Thread 组件语言：消息气泡、composer、建议 chips、会话列表。UI 需按 assistant-ui 官方风格（干净、细描边、圆角气泡）出稿。

### 4.1 布局结构（从上到下）

1. **面板头**（48px）：标题「《书名》· AI 伴读」（书籍空间标识，见 §4.3）+ 当前会话名（可点击重命名，行内编辑）+ 图标组：**新建会话 / 会话历史 / 收起面板**。
2. **会话历史弹层**（点头上的「会话历史」）：下拉列表，每项 = 会话名 + 最近时间 + 「⋯」（重命名 / 删除）。当前会话高亮。
3. **消息区**（滚动）：见 4.2。
4. **建议 chips 区**（无消息或空闲时显示）：按场景出 3–4 个建议问题，如「总结本章」「这段在讲什么」「作者的核心论点」。
5. **Composer 输入区**：见 4.5。

### 4.2 消息气泡

- **用户消息**：右对齐，主色浅底（暖色，如 #FBEFDD，UI 定稿）、深墨字、圆角 16px（右下角 4px）。
- **AI 消息**：左对齐，透明底或极浅灰底、圆角 16px（左下角 4px）、支持 Markdown 渲染（标题/列表/代码块/表格）。
- **AI 消息底部操作条**（hover 消息时浮现，否则半透明）：**复制 / 重新生成 / 点赞 / 点踩**。点赞点踩点击后图标变实心 + toast「感谢反馈」。
- **引用上下文卡片**：当消息带选中文本上下文时，消息上方渲染一个引用块（左侧 3px 主色竖条 + 浅暖灰底 + 原文截断两行 + 来源「《书名》· 第 3 章」小字）。点击展开全文。
- **流式生成中**：AI 消息尾部光标闪烁（3px 竖条 600ms 闪烁）；生成完操作条淡入。
- **工具调用展示**（如联网搜索）：折叠条样式「🔍 已联网搜索 · 3 个来源」可展开来源列表（站点名 + 链接标题）。
- **错误态**：红描边卡片「回答生成失败」+ 原因 +「重试」按钮。
- **停止生成**：生成中 composer 上方出现「■ 停止生成」文字按钮。

### 4.3 书籍独立空间（P0，catnuko 2026-10-28 拍板新增）

**每本书一个独立会话空间**，三条硬性规则：

1. **按书隔离**：每本书拥有自己独立的会话空间，该书的全部对话只保存在自己的空间里。「会话历史」弹层只列出**当前书籍**的会话，看不到其他书的任何会话。
2. **切书自动切换**：切换书籍时，AI 面板自动切换到目标书的空间——会话历史、当前会话、建议 chips 全部跟着换，**无弹窗、无确认**（取代 v1.0 的「是否新建会话」提示，该提示废除）。
3. **互不污染**：不同书的会话列表、会话命名、上下文互不可见互不影响；在 A 书里新建/删除/重命名会话不影响 B 书。

设计落点：

- 面板头（§4.1）增加空间标识：标题区显示「《书名》· AI 伴读」，让用户始终知道当前在哪个书的空间。
- 会话历史弹层顶部加一行小字空间说明：「《书名》的会话」，列表为空时显示空态「这本书还没有会话」。
- 书架页与阅读页之间的切书动效要体现空间切换：AI 面板内容区可给一个轻量淡入（150ms），不做翻页式大动效。
- 特写板：会话历史弹层（含某本书 3 条会话 + 另一本 0 条会话两个状态），证明列表按书隔离。

其他会话操作不变：新建会话（「+」直接替换，不弹确认）、行内重命名（Enter 确认 Esc 取消）、删除会话（确认弹窗「删除后不可恢复」destructive）。

### 4.4 联网搜索（catnuko 2026-10-28 拍板：**只做 UI 占位符，不接真实搜索**）

真实搜索功能等 catnuko 提供搜索接口后再接入。本档只定**占位符的样子**，让 UI 把位置和样式先画出来：

- composer 工具行（输入框左下）保留「🌐 联网搜索」toggle 位置，但**置灰禁用**：线性图标 + 灰字，hover 出 tooltip「搜索接口待接入」。
- **来源引用样式照常设计**（将来接入后直接用）：AI 消息里的来源以引用角标 [1][2] 呈现，消息底部「🔍 来源」折叠条列出链接（站点名 + 链接标题）——作为样式规范出稿，标注「占位」。
- 设置页保留「允许 AI 联网搜索」开关位置，默认**关**且置灰，说明文字「搜索接口待接入后可用」。
- 工具调用折叠条样式（§4.2「已联网搜索 · N 个来源」）照出，标注占位。

### 4.5 Composer（输入区）

- 多行文本框，默认一行高，超过 5 行内部滚动；Enter 发送、Shift+Enter 换行（placeholder 里注明）。
- 左下工具行：「🌐 联网搜索」toggle（**置灰占位**，见 §4.4）+ 「@引用」按钮（弹出当前书章节列表选择引用）。
- 右下：发送按钮（圆形 36px，主色，空输入时置灰禁用）；生成中变为「■」停止按钮。
- 有预填引用时：输入框上方显示引用 chip（原文截断 + ×可移除）。
- 字数不限制、不显示字数（克制）。

### 4.6 AI 笔记助手（笔记页内嵌，同一组件语言）

- 笔记页右侧固定 360px 助手栏：把选中笔记/摘录作为上下文（顶部显示「正在讨论：《书名》笔记 · <标题>」+ 可切换）。
- 能力按钮（composer 上方 chips）：「解释这段摘录」「帮我扩写成完整笔记」「基于这条笔记提问」。
- AI 生成的扩写结果带「保存为笔记」按钮。

### 4.7 空态

- 无任何会话时：「和 AI 聊聊这本书 🦌」（不用 emoji，用鹿角线性图标）+「你可以选中正文任意文字直接提问，或从下面选一个话题」+ 建议 chips。

## 5. 页面四：笔记与摘录

### 5.1 布局

- 顶栏：标题「笔记与摘录」+ 书籍筛选下拉（全部书籍 / 单本）+ 类型 tabs（全部 / 高亮 / 笔记 / AI 问答）+ 搜索框。
- 主区：摘录卡片瀑布/网格（2 列）。右栏为 AI 笔记助手（§4.6），可折叠。
- 选中某条笔记 → 右栏切换为**笔记详情**：原文引用块 + 我的批注（可编辑文本域）+ 高亮颜色标记 + 来源跳转「在书中查看」+ 操作（编辑 / 删除）。

### 5.2 摘录卡片

- 结构：高亮色细条（左上角，对应划线颜色）+ 原文（最多 4 行截断）+ 我的批注（若有，次级色）+ 书名·章节 + 时间 + AI 图标（若来自 AI 问答）。
- hover：上浮 + 出现「⋯」菜单（在书中查看 / 复制 / 删除）。
- 删除需确认弹窗。

### 5.3 状态

- 空态：「还没有笔记。阅读时划选文字即可创建高亮和笔记」+ 图示（选区 + 工具条小示意图）。
- 筛选无结果：同书架空态文案风格。

## 6. 页面五：⌘K 全局命令面板

> 功能已实现（代码在跑），UI 只出视觉稿。**以 assistant-ui/shadcn 命令面板语言为准**：居中弹窗 560px、顶部搜索输入、分组结果列表。

### 6.1 行为细节

- 输入即过滤；无输入时显示默认分组：**最近阅读（书）/ 最近笔记 / 快捷操作（新建会话 / 导入书籍 / 打开设置）**。
- 分组标题小字灰；结果行 = 图标 + 主标题 + 右侧次级信息（书名/时间）+ 选中行左侧 3px 主色条。
- 键盘：↑↓ 移动、Enter 执行、Esc 关闭；选中态底色 #F4F1EA（v1.2：原 #F4F5F7 冷灰改为暖色等值，catnuko 2026-10-28 批准）。
- 无结果：「没有匹配的结果」+ 建议「试试搜索书名或笔记内容」。

## 9. 动效规范

- 原则：动效只用于**反馈与过渡**，不做装饰动画；统一时长与缓动。
- 时长：微交互（hover、按下）100–150ms；弹层进/出 150–200ms；面板滑入 200–250ms。
- 缓动：进 `cubic-bezier(0.2, 0, 0, 1)`，出 `cubic-bezier(0.4, 0, 1, 1)`。
- 必做动效清单：划选工具条浮现（§3.4）、AI 消息流式光标、骨架屏 shimmer（1.5s 循环）、弹窗/Popover 缩放淡入、toast 底部滑入 2.5s 自动消失、侧栏 AI 面板滑入滑出。
- 尊重系统「减少动态效果」：该偏好下所有动效退化为直接切换（设计稿标注即可）。
